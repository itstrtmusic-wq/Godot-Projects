## Signal Foundry

[Signal Foundry](SignalFoundry/README.md) is a Godot 4.6 desktop workspace for visually authoring stereo JUCE effects and exporting VST3 source projects.

Open `SignalFoundry/project.godot` in Godot, or run `godot --path SignalFoundry`.
